TANGERINE LIBRARY ACCEPTANCE CHECKLIST (TXT)
Agent-output quality stack + Rust-class speed/safety + cross-platform/OS/hardware compatibility + accelerator parity
Date: 2026-03-02

INSTRUCTIONS
  This is a checklist. Unless explicitly marked OPTIONAL, every checkbox is REQUIRED.
  This document avoids language syntax and low-level implementation specifics. It defines:
    • Requirements (behavioral contracts)
    • Quality gates (what CI must enforce)
    • Exact tests (non-tautological, oracle-driven)
    • Documentation requirements (docs-as-tests)
    • Agent seamlessness requirements (agents see obligations and patches, not library wiring)

========================================================================================
A) GLOBAL TEST RIGOR POLICY (ANTI-TAUTOLOGY) — APPLIES TO EVERY LIBRARY
========================================================================================
[ ] Oracle Independence Rule: correctness tests MUST use an independent oracle (IR executor, independent impl, golden vectors, or metamorphic invariants).
[ ] Dual-Path Rule: critical operations MUST be validated via two different computational paths (e.g., decode vs independent parser + golden vectors).
[ ] Failure-Mode Coverage Rule: success, failure classification, recovery, cleanup, determinism must all be tested.
[ ] Mutation Gate: each library defines fault injections; CI must show tests fail for each injected fault.
[ ] Differential Schedule Rule: schedule-sensitive behavior tested under baseline + randomized (seeded) + bounded exploration (where applicable).
[ ] Cross-Platform Oracle Rule: same seeds/inputs produce identical outputs (or defined envelope) across supported OS/arch/hardware.
[ ] Roundtrip-alone ban: encode→decode is not sufficient unless paired with an independent oracle/golden vectors.
[ ] Deterministic seeds everywhere: every generative/fuzz/replay test records seeds and is replayable.
[ ] Evidence bundle standard: failures emit minimal repro + full traces + IR/cert dumps (as applicable).
[ ] Repro capsule requirement: each Finding is reproducible by one command plus captured environment fingerprint.

========================================================================================
B) GLOBAL QUALITY GATES — APPLIES TO EVERY LIBRARY
========================================================================================
[ ] Determinism: deterministic by default OR explicitly labeled nondeterministic with comparator envelope and rationale.
[ ] Structured errors: stable error codes + structured context (spans where applicable).
[ ] Capability discipline: no hidden side effects; side effects require explicit capabilities where applicable.
[ ] Cross-platform: passes on supported OS/arch matrix (at minimum Linux/macOS/Windows; x86_64/arm64).
[ ] Fuzzing: parsers/decoders/protocol handlers/unsafe boundaries have fuzz harnesses + persisted corpora + minimization.
[ ] Property tests: core invariants have property tests with shrinking and seed replay.
[ ] Docs: reference docs + runnable examples + how-it-fails + security + performance + compatibility notes; examples executed in CI.
[ ] Performance: budgets exist where relevant; baselines versioned; regression detection uses robust stats.
[ ] API stability: API diff gate (semver); deprecations have migration path and tooling support.
[ ] Agent seamlessness: obligations/fix-its/profiles hide wiring; context packs include minimal intent summaries + examples.

========================================================================================
C) PLATFORM + HARDWARE COMPATIBILITY MATRIX — APPLIES TO ALL LIBRARIES
========================================================================================
[ ] Supported matrix defined: OS × arch × libc/CRT × CPU families × GPU backends × driver versions (where applicable).
[ ] Same corpus seeds and inputs are run across the matrix; outputs compared with exact/envelope comparators.
[ ] Platform results include normalized Finding IDs so cross-platform reproducibility is obvious.
[ ] Cross-platform divergence beyond envelope is a PLATFORM_DIVERGENCE_BUG and blocks release.

========================================================================================
D) PER-LIBRARY CHECKLISTS (ALPHABETICAL; NO PRIORITY IMPLIED)
========================================================================================
