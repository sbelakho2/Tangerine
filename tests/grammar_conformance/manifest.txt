# tests/grammar_conformance/manifest.txt — grammar-conformance corpus.
#
# This corpus is DELIBERATE, not derived from either parser's behaviour: each
# specimen encodes a decision about the intended language (see README.md for
# the per-decision table and the per-file header comments for the anchors).
#
#   accept <path>   the program must parse with ZERO error diagnostics
#   reject <path>   the program must record AT LEAST ONE error diagnostic
#
# Both parsers enforce the same expectations:
#   - the OCaml seed parser (stage0_ocaml/selfcheck/tg_parse_parity.ml, the
#     seed-side corpus check), and
#   - the bootstrap kernel parser (tg_compiler/parser.tg) run in the seed VM
#     by tg_compiler/parse_parity_probe.tg.
# A case that changes side in either parser fails the lane.
#
# `accept` cases are either (a) intentional language with a spec/doc anchor or
# (b) a documented bootstrap-accommodation the current sources still require —
# each header says which. `reject` cases are syntax the intended grammar
# forbids; they are only listed here after the SEED also rejects them, so the
# kernel can be tightened without breaking seed/kernel parity.
#
# Add a case: write the specimen under pos/ or neg/ with a header comment
# giving case, decision and anchor, then register it here.
